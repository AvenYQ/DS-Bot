# DS Bot「小朝廷值房图」插件：需求说明

版本 3，2026-11-11（第二段到第四段做完后补写：可爱化外观、镜头、交互巧思、音效。第七节是 10 月 30 日拍的板，第八节是这次新加的玩法和验收），写给接手的人。先读桌面上的《DS-Bot交接文档.md》，了解工作规矩、分支和发版流程，再读这份。

---

## 一、要做什么

把 Aven 之前为 Grok Bot 做的网页版「小朝廷值房图」（3D 紫禁城，每位官员一个动态 Q 版小人）接进 DS Bot：

1. 做成 DS Bot 里的一个**独立入口**。点开后，整页显示值房图，不开浏览器，也不另开窗口。
2. 值房图里每位官员的状态，**实时对接 DS Bot 里对应 bot 的真实运行状态**，替换掉现在的示例数据。
3. 代码写成**独立的插件模块**，和聊天界面分开，方便以后同步作者（upstream）的更新。

**素材**：桌面上的 `xiaochaoting.zip`，解压后是 `xiaochaoting/index.html`（单文件，约 850 行）和 `README.md`。README 里有代码地图，先读它。

## 二、入口（已和 Aven 确认的样式）

参照 Grok Bot 侧栏底部的「连接应用」按钮（Aven 给过截图）。

### 1. 侧栏展开时
- 位置：侧栏底部那一行，用户头像和名字的**右边**。
  - 现在 DS Bot 这一行只有 `AccountLauncher`（`ds-bot/src/client/sidebar.js` 里的 `bt-leftcol-foot`）。
- 平时：一个圆形按钮，约 36×36，白底，带细描边和轻阴影，样式和侧栏顶部的搜索、新建按钮一致。按钮里是**新 app 图标的缩小版**，见下面第 3 条。
- 鼠标悬停：按钮**向左展开成一个胶囊**，盖住名字那块区域。
  - 胶囊里是图标加文字「小朝廷值房」。
  - **已定：**文字右边放一个小计数，比如「3 位当值」：当前正在工作的官员数（有 running 或在群聊里干活的都算），没有人当值时就不显示计数。
  - Grok 的胶囊里放的是几个应用图标，我们放计数。
  - 展开和收回用 app 现有的弹簧动画（`ds-bot/src/client/motion.js` 里的 spring），约 0.2 秒。左边的头像不能被挤动或跳动。
  - 鼠标移开就收回。
- 点击（按钮或胶囊都行）：打开值房图。

### 2. 侧栏收起成头像栏时（88px）
- 只显示图标，不展开胶囊。
- 位置：头像栏底部，「新建（+）」按钮下面、用户头像上面。
  - 也就是现在 `bt-leftcol-foot-rail` 里：展开侧栏按钮 → 新建 → 【值房图图标】→ 头像。
- 样式：和上面的「展开侧栏」「新建」两个图标一致，32×32，没有底色，悬停时出现浅灰底。
- 悬停：显示 tooltip「小朝廷值房」。

### 3. 入口图标
- 用新 app 图标里的**朱红气泡印**本身，不要外面米白的圆角方块底。
  - 设计源文件：`app/assets/icon-seal-source.html`。
  - 气泡外形的路径（坐标系 1024）：`M290 232 H734 Q792 232 792 290 V650 Q792 708 734 708 H420 L312 800 L340 708 H290 Q232 708 232 650 V290 Q232 232 290 232Z`
  - 里面是一圈米白细框、一道飞檐弧线、三个小圆点。
- 小尺寸（16 到 20px）下：
  - 去掉纸纹颗粒和边缘抖动，保留歪 6 度和朱红色；
  - 内框线可以省掉，只留飞檐和三点，保证清楚。
- 做成内联 SVG 组件，颜色走主题变量。
- **已定：侧栏展开时的圆形按钮里用彩色版**（朱红用 `--bt-cinnabar`，深色模式下它会自动变亮）。
- **已定：头像栏里用单色版**，跟「展开侧栏」「新建」两个图标同色（`--bt-ink` 的 72%），悬停时变深。单色版就是气泡外形描边加里面的飞檐和三点，不填色。

## 三、打开后的页面

- **位置**：值房图占据右边的主区域，也就是聊天区的位置。左边侧栏保持不动。
- **顶部**：一条标题栏，左边「小朝廷值房」，右边一个关闭按钮（×）。按 Esc 或点 × 回到打开前的那个对话。
- **点侧栏里的任何官员**：直接切到和他的对话，值房图关闭。
- **画面**：Q 版紫禁城，用 three.js 画出来，细节见第八节。包括：
  - 建筑、午门宫墙、金水河和树；天色和灯光按时辰走，夜里当值的衙门亮窗、宫灯亮起来；
  - Q 版小人和头顶气泡；
  - 右侧的官员卡片（起居注）、名册。
- **去掉**页面上所有「示例数据」字样。
- **字体和配色**：跟 app 走（见交接文档的字体部分）。Aven 非常讨厌细字，卡片和名册里的字不能比 13px 小，不能用细体。
- **深色模式**：卡片、名册、标题栏要适配。3D 场景本身可以保持原样。

## 四、数据对接（核心）

### 1. 官员和 bot 的对应
- `index.html` 里的 `MIN` 表有 20 位官员，每位有 id、name、title、dept 和所在建筑 b。
- DS Bot 里的 bot 名字形如「首辅·张居正」「户部尚书·和珅」。
- 对应规则：
  - **按名字匹配**：bot 名字里包含 `MIN.name`，就对上。
  - 另外留一个手动对照表，名字对不上时用。
- DS Bot 里有、`MIN` 里没有的 bot：
  - 自动生成一个小人，袍色取头像底色（`bot.avatar.color`）；
  - 放进它所在侧栏分组对应的建筑，没有对应建筑就放进「编外」。
- `MIN` 里有、DS Bot 里没有的官员：
  - 比如 `cl`（Claude·南书房行走），以及 Grok 那边才有的官员；
  - **已定：不显示。** 场景里不放他的小人，名册里也不列。他所在的建筑如果没有别的官员，建筑照常保留，只是空着。
- **分组顺序**：名册里的分组顺序以 DS Bot 侧栏的分组为准，也就是 roster 的 sections 顺序，不再写死 `DEPTS`。以后 Aven 在侧栏里改分组、拖动排序，值房图跟着变。

### 2. 实时状态从哪来
DS Bot 的客户端里已经有每个 bot 的实时状态，侧栏 `BotRow` 显示的角标、绿点、口头禅都从这里来。看 `ds-bot/src/client/sidebar.js` 的 `BotRow` 和 `ds-bot/src/client/mark.js` 的 `botState`：

| 数据 | 来源 | 含义 |
|---|---|---|
| `running` | `useSessionStatus(map => map.get(part)?.running)` | 这个 bot 正在跑一轮 |
| `doing` | `useActivity(map => map[id])` | 正在做什么：thinking / searching / sending / working，以及工具名 |
| 群聊里干活 | `useWork(work => work.rooms)` | 在某个群聊里发言或干活（侧栏的 `away`） |
| `alert` | `roster.questions[part]`、`useWork(work => work.approvals)` | 在等 Aven 回答问题，或等他批准 |
| `waiting` | `useWork(work => work.waiting[id])` | 在等别的 bot 或群 |
| `done` | `completionUnread && !pendingInteraction` | 办完了，Aven 还没看（侧栏的「办」字角标） |
| 口头禅 | `phrasePool(bot, ...)`（`cells.js`） | 头顶气泡的文字 |
| 定时任务 | `ds-bot/src/client/schedules.js` | 该 bot 的例行时辰，替代示例的排班 `sch` |

**要求**：把 `BotRow` 里推导状态的那段逻辑抽成一个共享的 hook，比如 `useBotLiveState(id)`。侧栏和值房图都用它，保证两边永远一致。不要另写一套。

### 3. 状态怎么显示

| DS Bot 状态 | 值房图状态 | 小人表现 |
|---|---|---|
| 正在思考 | 当值（思考） | 伏案；头顶气泡显示口头禅，比如「权衡利弊…」 |
| 正在用工具 | 当值 | 伏案；气泡显示在做什么，比如「翻阅卷宗…」，用 `workPhrase` |
| 正在回话 | 当值 | 伏案，气泡「回奏中…」 |
| 在群聊里 | 议事（新状态） | 走到太和殿广场；同一个群里的官员站在一起。复用现有的「赴朝 / 上朝 / 退朝」路线动画 |
| 等 Aven 回答或批准 | 待批（新状态） | **已定：**小人头顶一枚朱红小印章（不用红点），形制参照聊天里的「准」字印：朱红实心方印，微微歪着，带纸纹颗粒，可以轻微上下浮动吸引注意；卡片顶部写「等皇上定夺」，附一个「去批复」按钮 |
| 等别的官员 | 候（新状态） | 站着，气泡写「等 某某」 |
| 办完未读 | 已办 | 头顶一个「办」字小印，和侧栏的角标一样；Aven 点开对话后消失 |
| 出错 | 出错 | 沿用现有的 `err` 样式 |
| 空闲 | 候旨 | 沿用现状 |
| 夜里空闲 | 歇息 | 沿用现有的按时辰逻辑（`sky(h)`） |

- 状态变化时，小人的动作要**过渡自然**，比如从候旨起身走到案前，不能瞬移。
- 实时性：直接订阅上面那些 store，状态一变就刷新，**不要轮询**。

### 4. 官员卡片（起居注）
点小人或名册里的名字，右侧弹出卡片：
- 头像（用 DS Bot 里的头像，GIF 也要能动）、名字、官职、分组、职掌（沿用 `MIN.duty`；新官员留空或用 bot 简介）。
- **当前状态**：同第 3 节，带开始时间，比如「当值 · 翻阅卷宗 · 3 分钟前开始」。
- **今日起居注**：今天这个 bot 的几轮对话，每轮一行，显示时间和一句话摘要（取 session 预览），最多 8 条。
- **例行时辰**：这个 bot 的定时任务和下次运行时间。
- 按钮「去对话」：跳到和他的对话。

## 五、技术要求

1. **模块位置**：新建 `ds-bot/src/client/court-board/`，所有值房图代码放在里面，入口在侧栏（`ds-bot/src/client/sidebar.js`）。尽量少改作者原有的文件，方便以后合并 upstream。
2. **不能用 CDN**：
   - `index.html` 原来从 cdnjs / jsdelivr 加载 three.js r128、OrbitControls、BufferGeometryUtils，从 Google Fonts 加载「站酷小薇」字体。
   - 全部本地打包：three 用 npm 的 `three`（现在是 0.187），字体用 `@fontsource/zcool-xiaowei`，都经由 esbuild 打进插件。
   - app 要能离线用，而且 DSH 页面有内容安全策略（CSP）。
3. **按需加载**：只在第一次打开值房图时才加载 3D 相关代码，用动态 import，不能拖慢 app 启动。
4. **省资源**：
   - 值房图关闭、窗口最小化或切到后台时，停掉渲染循环（`loop()` 的 requestAnimationFrame），不要在后台持续耗 GPU。
   - 场景没动静时也停帧（`render.js` 的 `shouldRender`）；有人走动、宣旨、点选时再醒过来。
   - 电池供电或帧率掉下来时自动降画质（像素比、阴影、雨雪数量）。
   - 关闭时释放 WebGL 资源。
   - 像素比最多 2。
5. **自适应**：主区域会随侧栏展开、收起而变宽变窄，要监听尺寸变化，更新相机和渲染尺寸。
6. **不改动官员数据**：值房图只读状态，不写任何 bot 配置、总册、指令文件。「去批复」「去对话」只是跳转到对话。
7. **测试**：
   - `ds-bot` 里补测试：名字匹配、状态映射、共享 hook 和侧栏一致。
   - `npm test` 和 `npm run lint` 必须全过，包括样式债检查（颜色用 `--bt-*` 变量，圆角用规定档位）。

## 六、验收标准（逐条截图或录 GIF 给 Aven 确认）

1. 侧栏展开时，底部头像右边有圆形印章按钮；悬停平滑展开成「小朝廷值房」胶囊，头像不动；鼠标移开收回。
2. 侧栏收起时，头像栏底部「+」下面只显示印章图标，悬停有 tooltip。
3. 点击后，主区域显示 3D 值房图，侧栏不动；× 或 Esc 回到原来的对话。
4. 给某位官员发一条会调工具的消息，值房图里他的小人在 1 秒内变成「当值」，气泡显示在做什么；回复结束后变成「已办」，Aven 点开对话后变回「候旨」。
5. 官员在等 Aven 拍板时，小人头顶有朱红小印章，卡片里「去批复」能跳到对应对话。
6. 在群聊里发言的官员走到太和殿广场。
7. 断网时值房图照常打开，字体正常。
8. 值房图关闭后，CPU / GPU 占用回到打开前的水平（用「活动监视器」看）。
9. 深色模式下卡片、名册可读，没有细字。
10. 第八节的玩法逐项过一遍：点人回礼、御驾巡视、三处彩蛋、奏折堆待办、拖拽派活（「且慢」一次都不发、「准奏」只发一次）、音效开关（默认关、记住选择）。

**流程**：全部在 `aven/custom` 上本地提交，不推送。每段做完由刑部逐项看图、跑检查；整段做完，截图和录屏一次呈 Aven，他点头后才推送、发版。

## 八、这次新加的玩法和实现（2026-11-11）

### 1. 外观：可爱的 Q 版紫禁城
- 屋顶铺瓦垄，檐角有走兽，台基上围汉白玉栏杆，地砖和金水河的水面会缓缓流动，院里种了松树和花树。
- 重复的构件（瓦垄、走兽、栏杆、树）合成一批来画，省显卡；三角面数从约 28 万降到约 17.6 万。
- 只求两个字：圆润。不做写实、不堆彩画；斗拱、和玺彩画这类复杂装饰不做。贵气靠宫灯和金顶点到为止。
- 天色、灯光、雾、雨、雪分开调：白天亮堂，傍晚偏暖，夜里靠月色和宫灯。

### 2. 镜头：点谁看谁
- 点小人，镜头平滑推近到他跟前；机位会绕开别的屋顶，不会被前景挡住。
- 右下角一张小地图，点哪儿镜头去哪儿；上面有一道淡淡的视线扇形，表示现在看的方向。
- 标题栏三个预设视角：全景、内阁、六部，点一下就到。
- 标题栏还有一只眼睛：御驾巡视。镜头沿中轴从午门一路走到乾清宫，两边的衙门都看得到；按 Esc 随时停下。

### 3. 点小人：他会回礼
- 点一下小人，他头顶冒一句话，内容看他当时在干什么：当值、待批、待答、等别的官员、候旨、夜里歇息，六种各六句。
- 连着点同一个人，一次换一句，不会重样；手上有差事时，话里会带上那件差事的名字。
- 台词在 `court-board/lines.js`，句子里可以嵌 `{task}`；没有差事可报时，自动挑不带 `{task}` 的句子，不会漏出花括号。

### 4. 三处衙门的彩蛋
- 点钦天监的衙门：一张星图，附一句今夜的卦象。
- 点翰林院：苏轼新画的一幅画，画角有小字。
- 点内承运库：本月账目——进项、支出、结余。
- 都是小浮层，点一下收起来；文字也在 `lines.js`。

### 5. 门口的奏折堆：点开看他在等什么
- 每位官员门口有一堆奏折，堆得越高，等他处理的事越多。
- 点这堆折子，弹出他最近五条待办：等他批的、等他回话的，新的在上面；一条没有就写「他这会儿手上清闲，没压着折子」。
- 鼠标移上去，折子堆下面亮一圈金环，提示这里能点。

### 6. 把奏折拖给官员派活（要皇上点头）
- 标题栏有一枚「奏折」，按住拖到哪位官员身上都行。
- 松手先弹一张卡：发给谁、发什么，下面是「且慢」和「准奏」两个按钮。**点「准奏」才真的把消息发出去；点「且慢」就收回，谁也不惊动。**
- 发出去以后如果没送到，卡片留着，下面一行红字说明没送出去，按钮变「再试一次」；再点发的还是同一份，不会重复发两遍。
- 卡片文字在 `lines.js`；发送逻辑在 `bridge.js`：`dispatch` 必须带 `confirmed: true`，没有就直接拒绝，一条消息都不发。

### 7. 声音：默认关着
- 四种：晨钟、暮鼓、宣旨、小太监跑腿。全部用浏览器现场合成，不用音频文件，不增加包体积。
- 标题栏一只喇叭，开着、关着各有一条提示；选择记在本机，下次打开还是上次那样。
- 默认关。关着时一下都不响，也不建音频上下文。

### 8. 流畅：不动就不画
- 场景没动静时停止重绘（`render.js` 的 `shouldRender`）；有人走动、宣旨、点选时再醒过来。
- 电池供电或帧率掉下来时自动降画质。
- 真机（Mac + Chrome，1280×800）白天、夜里、开会、推近都是 60 帧；验收标准见第六节。

### 9. 代码在哪
- `court-board/scene.js`：场景、相机、人物；`palace.js`：宫殿和衙门；`layout.js`：位置表。
- `court-board/render.js`：颜色、灯光、雨雪雾、停帧、画质；`weather.js`：南京的天气。
- `court-board/index.js`：值房图外壳（标题栏、奏事簿、名册、官员卡片）；`play.js`：巡视、彩蛋、回礼、奏折堆、拖拽派活。
- `court-board/plaques.js`：门匾文字；`lines.js`：台词、彩蛋文字、确认卡文字；`bridge.js`：读状态和待办、发消息；`sound.js`：音效。
- 界面中文在 `ds-bot/src/client/i18n.js` 的值房段；字不小于 13px、不用细体。
