# DS Bot（Aven 定制版）交接文档

更新于 2026-11-11（北京时间）。写给接手的人或 agent：**先读完这份，再动代码。** 这份文档随代码放在仓库的 `docs/aven/`，改动它请一起提交。仓库根目录的 `AGENTS.md` 是上游作者写的 agent 规矩，也要读；两份冲突时，以这份（Aven 的规矩）为准。

## 一、这是什么

- **DS Bot**：作者 Fei2411 的开源项目（GitHub：`Fei2411/DS-Bot`）。
  - 核心是 DeepSeek Harness（DSH）的一个插件 `ds-bot/`；
  - 外面包着一个 Electron 桌面 app `app/`，app 内置一份固定版本的 DSH。
- **Aven 的定制版**：fork 在 `AvenYQ/DS-Bot`，做成一个独立的 Mac app「DeepSeek Bot」（bundle id `io.github.fei2411.deepseekbot`），装在 `/Applications/DeepSeek Bot.app`。
- **用户的 bot 团队**：一套"小朝廷"，首辅·张居正、次辅·王安石、六部尚书、内廷各监等，每个 bot 有自己的头像（GIF）和口头禅。
- **当前版本**：`0.3.2-aven.6`（2026-11-11 发布并已装到 Aven 的 Mac）。底子是作者 0.3.2，加上 Aven 的定制。

## 二、Aven 的工作规矩（务必遵守）

1. **一律用中文回复。**
2. **先确认，再发版。** 推到 `aven/custom` 会自动发版（见第四节），所以界面改动要先截图给 Aven 看，他说可以再推。他说"别急着打包"时，只在本地改。
3. **他说"先别急着改，把发现和策略发我"时**，只汇报原因和方案，等他同意再动手。
4. **要细致。** Aven 对界面很挑剔，粗糙的方案会被打回（原话："你好好设计一下，不要搞得很粗糙"）。界面改完必须看真实渲染截图，不能只看代码或测试。
5. **不要重犯老错误**，第七节列了已经踩过的坑。
6. 删除文件、对外发消息、付费操作，先问 Aven。

## 三、代码与分支

- **仓库**：`AvenYQ/DS-Bot`。Aven 的 Mac 上本地克隆在 `~/DS-Bot`，已经是最新的 `aven/custom`。
- **`aven/custom`**：唯一的工作和发布分支（也是仓库默认分支）。
  - 旧的 `aven/dev`、`release/*` 分支已经过时，**不要用**。
  - 想隔离改动，就从 `aven/custom` 拉一个临时分支，改完合回 `aven/custom`。
- **上游**：作者的 `Fei2411/DS-Bot` main，CI 每天自动合并（见第五节）。
- **版本号**：`app/package.json` 和 `ds-bot/package.json` 必须一致，格式 `作者版本-aven.N`。**不要手动改版本号**，CI 会自己加。

### 目录

- `ds-bot/`：DSH 插件。
  - 界面在 `ds-bot/src/client/`，服务端在 `ds-bot/index.js` 和 `ds-bot/src/host/`。
  - `ds-bot/client.js` 是生成文件：改完 `src/client/` 必须 `npm run build`，两个文件一起提交，**不要手改 `client.js`**。
- `app/`：Electron 外壳。
  - `src/main.mjs`：主进程，包括自动更新、⌘Q 退出。
  - `src/window-frame.mjs`：Mac 窗口外观，标题栏高 40px，红绿灯位置 `{x:16, y:13}`，即红绿灯中线在 y=20。
  - `src/preload.cjs`：给页面打 `data-windows-titlebar`、`data-caption-lights`（Mac）等标记。
  - `src/updates.mjs`：检查 `AvenYQ/DS-Bot` 的 release，安装包名 `DeepSeek-Bot-<版本>-mac-arm64.zip`。
- `docs/aven/`：fork 自己的文档（就是这里）。上游的 `docs/` 不要往里加 Aven 的东西。

## 四、改代码、测试、发版

### 本机环境（Aven 的 Mac，已配好）

- Node：`v24.19.0`，装在 `~/.local/opt/node-v24.19.0`，由 `~/.local/bin/node` / `npm` / `npx` 指向；npm 是 11.17.0。
  - 不要动 `~/.hermes/node`，那是 Hermes 自己用的 Node 22，不归我们管。
- 依赖已装：`ds-bot/`、`app/` 的 `node_modules`，以及 `ds-bot/dev/harness`。
- 2026-11-11 基线：`ds-bot` 的 `npm test` 共 2148 条，0 失败。

### 每次改动都要跑

```sh
cd ~/DS-Bot/ds-bot
npm run build                          # src/client → client.js
npm test                               # 单元测试；client.js 过期也会失败
node scripts/build-client.mjs --check
npm run lint
cd ../app && npm test                  # 改了 app/ 时
```

- **样式债检查**（`ds-bot/test/style-debt.test.js`）：
  - 颜色必须用 `--bt-*` 变量；
  - 圆角只能用 0/4/6/8/10/12/16/18/20/22/999px/50%，比如 7px 会挂。
- **依赖坑**：
  - 上游升 DSH 版本或加了测试包后，`npm test` 会报 `ERR_MODULE_NOT_FOUND`，跑一次 `npm run harness` 即可。
  - npm 11 会提示 `allow-scripts`：如果删掉 `node_modules` 重装后出问题，跑 `npm approve-scripts --allow-scripts-pending` 批准这几个包（esbuild、node-pty、koffi 等，都是项目正常依赖）。

### 发版（自动）

1. 在 `aven/custom` 上提交，**先 `git pull`**（CI 会往这个分支推 release 提交），再 `git push origin aven/custom`。
2. 只要改动涉及 `ds-bot/**` 或 `app/**`，GitHub Actions 的 `.github/workflows/aven-sync.yml` 就会：
   - 跑测试；
   - 把版本号加一（`-aven.N+1`），提交并打 tag；
   - 在 Apple 芯片机器上编译 macOS app；
   - 发 release，附件 `DeepSeek-Bot-<版本>-mac-arm64.zip`。
   - 只改 `docs/` 不会发版。
3. 整个过程约 15 分钟。Mac 编译机偶尔排队后被取消，被取消就重跑失败的 job：
   ```
   gh run rerun <run-id> --failed -R AvenYQ/DS-Bot
   ```
4. 测试失败时不会发版。看 Actions 日志修好再推。

### 装到 Aven 的 Mac

两种方式：

- **自动更新**：app 里弹「立即更新」，点一下即可。它会下载 zip、用 sha256 校验、替换 `/Applications/DeepSeek Bot.app` 再重开。日志在 macOS 临时目录的 `ds-bot-update-*/swap.log`。
- **手动安装**：
  1. 下载 release 的 zip 到 `~/Downloads`，核对 sha256；
  2. 先退出 app，再解压替换 `/Applications/DeepSeek Bot.app`；
  3. 删除旧安装包。

## 六、Aven 定制了什么（改代码前先知道这些，别误删）

### 侧栏（`ds-bot/src/client/sidebar.js`）

- **分组 / 置顶 / 拖动排序**：
  - 置顶的 bot 以方块排在侧栏顶部，第一个主 bot 默认置顶（`sectionGroups`）；
  - 长按 280ms 拖动行、方块、分组标题，也能把 bot 拖进别的分组（`drag-sort.js`）；
  - 分组标题带颜色点，可以就地改名，有 + / … 菜单（`SectionHeader`）。
- **分组数据**：用的是作者 0.3.2 的 id 分组 `{id, name, collapsed, color}`，bot 上记 `sectionId`。
  - 我们旧版按名字分组的数据，会在 `ds-bot/src/host/sections.js` 的 `migrateLegacySections` 里自动迁移，id 取名字的 sha1：`sec-xxxxxxxx`；
  - 拖动排序走 `arrangeEntries`（channel 里的 `arrange-entries`）。
- **顶部按钮带（2026-11-11 刚做完，Aven 认可）**：
  - Mac 上，侧栏顶部的 文件夹 / 搜索 / 新建 / 收起 四个按钮，和红绿灯**在同一行、同一条中线**上；
  - 按钮是 28px 无边框图标，hover 才出底色。
  - CSS 在 `styles.js`，搜 `data-caption-lights` 和 `.bt-side-top`。
  - **关键**：`.bt-side-top` 必须 `flex:none`，否则列表一长，这一行会被压扁，按钮跑到红绿灯上方（踩过的坑）。
- **收起后的头像栏**：滚动条完全隐藏（`.bt-side.bt-rail>.bt-list` 的 `scrollbar-width:none`），Aven 不要那道灰线。
  - 展开时的列表滚动条平时透明，hover 才显示。
- **账户菜单里的「切换到经典 Agent 模式」必须保留**：作者 0.3.2 删了，Aven 因此回不去原来的主界面，我们加回来了，测试 `account-sign-out.test.js` 也在检查它。
- **侧栏外层**：`index.js` 里用 `OutletSidebar` 包着 `TeamSidebar`。`verifySidebar` 必须比对 `OutletSidebar`，比对错了侧栏会反复重新挂载，聊天区会滑到侧栏底下（踩过的坑）。

### 给别的插件留的插槽（`ds-bot/src/client/index.js` 的 `BOT_OUTLETS`）

- `ds-bot.sidebar.foot`：侧栏底部，别的插件可以放东西（宽版）。
- `ds-bot.model.effort`：模型菜单里的思考强度条，别的插件可以替换（`model-menu.js` 里 `actions.renderEffort`，没人替换时用自带的 `EffortBar`）。
- 声明插槽的选项名是 `children`，不是 `slots`（踩过的坑）。
- 这两个插槽原本给 Aven 的 Dune 主题插件用，**现在 Aven 已决定 DS Bot 和 DSH 插件解耦**：DS Bot 只更新自己的 app，不再维护插件那边的联动。插槽留着无害，不要为插件再加东西。

### 聊天区

- **GIF 头像**：每个显示位置单独一份 blob 拷贝，点击头像时动图不会从头播（`mark.js`）。
- **口头禅**：每个 bot 最多 6 条，工作时代替"思考中…"显示（`phrases.js`、`cells.js`、`activity-row.js`）。
- **贴底滚动**（`tail-keeper.js`）：内容变长保持贴底；回复结束内容变短时先撑住再缓缓收回；对话区变宽导致变短时不撑。
- **空过程组收起**（`process-groups.js` 标 `data-bt-empty`）；**气泡节奏**对标 Grok：同一人连续 4px，换人 14px（`data-bt-gap`）。
- **字体**：
  - 聊天正文默认 15px、行高 24px；
  - 全局 `-webkit-font-smoothing:auto`，Aven 讨厌细字和颗粒感。
- **朱批印章**：用户回复"准 / 驳回 / 知道了"，会在大臣气泡角上盖章，三种形制（`.bt-stamp`，`seal.js`）。
- **值房图**（`court-board/`）：小朝廷值房看板，`sectionOf(roster, bot)` 按分组排座次。

### app 外壳

- 身份是 DeepSeek Bot：`electron-builder.yml`、图标是宣纸底朱红印章气泡。
  - **不要运行 `npm run icon`**，它会用旧的小鲸鱼覆盖新图标。
- 自动更新指向 `AvenYQ/DS-Bot`；苹果菜单有「退出 DeepSeek Bot」（⌘Q）。

## 七、踩过的坑（不要再犯）

1. **界面问题只看测试不够**：测试全过、用户画面还是错，这种事发生过多次。界面改动必须看真实截图，最好在 Aven 的 Mac 上看，Linux 上没有苹方和宋体。
2. **flex 列被压扁**：竖向 flex 容器里的固定高度行要加 `flex:none`。
3. **红绿灯对齐**：中线在 y=20，按钮要和它对齐；全屏时没有红绿灯，按钮不需要让位（`:not([data-fullscreen])`）。
4. **合并上游时整块保留旧代码**：作者重写的组件，用我们的旧版整块覆盖，会丢掉作者的新功能，还可能留下多余的 CSS（例如 0.3.2 合并后，`.bt-sec` 的旧 CSS 让分组标题下方出现大空白）。
5. **别动 Aven 的数据**：不要碰 `~/.ds-bot`、`~/.dsh` 里的数据和 bot 配置。小朝廷的制度另有「南书房」体系负责，交接文档在 `~/Desktop/知识库/70-小朝廷/10-项目/小朝廷交接文档.md`。
