# DS Bot（Aven 定制版）交接文档

更新于 2026-10-31 09:50（北京时间）。写给接手的人或工具：先读完这份，再动代码。这份文档随代码放在仓库的 `docs/aven/`，改动它请一起提交。

---

## 一、这是什么

- **DS Bot**：作者 Fei2411 的开源项目 DeepSeek-Bot（GitHub：`Fei2411/DS-Bot`）。它是 DeepSeek Harness（DSH）的一个插件，外面包着一个 Electron 写的 macOS 桌面 app。
- **Aven 的定制版**：fork 在 `AvenYQ/DS-Bot`。目标是做成一个独立的 Mac app，界面和交互对标 **Grok Bot**（Aven 日常在用，也是所有 UI 问题的参照物）。
- **用户的 bot 团队**：一套"小朝廷"，首辅·张居正、次辅·王安石、六部尚书、内廷各监等，每个 bot 有自己的头像（GIF）和口头禅。

## 二、Aven 的工作规矩（务必遵守）

1. **一律用中文回复。**
2. **先确认，再打包上传。** 每一处改动都要先截图或录 GIF 给他看，他说可以才打包。他说"别急着打包/上传"时，只在本地改。
3. **不要重犯老错误。** 例如 Mac 的三个红绿灯按钮不居中。
4. **安装包放进「下载」文件夹，装到「应用程序」**，并删除旧的安装包和旧 app。
5. **Grok Bot 是标准答案。** 他说"看 grok"时，就去 Grok Bot 里实际看、实际量，再照着改。
6. 他会说"你先别急着改，把发现和策略发我"，这时只汇报原因和方案，等他同意再动手。

## 三、代码与分支

- **代码仓库**：`AvenYQ/DS-Bot`（公开 fork）。本地克隆在 `~/DS-Bot`，换了环境要重新 clone。
- **`aven/dev`**：日常开发分支，所有改动先提交到这里。
- **`aven/custom`**：发布分支（也是仓库默认分支）。把 `aven/dev` 合进来、push，就会触发 CI 编译和发版。
- **`upstream`**：作者的 `Fei2411/DS-Bot` main 分支。

目录结构：

- `ds-bot/`：DSH 插件，所有界面都在 `ds-bot/src/client/`。
  - 改完必须 `npm run build`，它会重新生成打包后的 `ds-bot/client.js`。
  - 测试：`npm test`，目前 1292 条，全部通过。
  - 检查：`npm run lint`。
  - 测试里有"样式债"检查：颜色必须用 `--bt-*` 变量，圆角只能用 0/4/6/8/10/12/16/18/20/22/999px/50%。
- `app/`：Electron 外壳。
  - `src/main.mjs`：主进程。
  - `src/preload.cjs`：Mac 窗口外观、红绿灯位置。
  - `src/updates.mjs`、`src/mac-update.mjs`：自动更新。
  - 测试：`npm test`，目前 212 条，全部通过。
- **版本号**：`app/package.json` 和 `ds-bot/package.json` 必须一致，格式是 `作者版本-aven.N`，例如 `0.2.4-aven.3`。

## 四、发版流程

1. 在 `aven/dev` 上改好，跑通两边的测试，提交。
2. 把 `aven/dev` 合进 `aven/custom` 再 push：
   ```
   git checkout aven/custom && git merge aven/dev && git push fork aven/custom
   ```
   版本号冲突时保留 `aven/custom` 那边的。
3. GitHub Actions 的 `.github/workflows/aven-sync.yml` 会自动：
   - 把版本号加一（如果 `v当前版本` 这个 tag 已存在，就变成 aven.N+1）；
   - 跑测试，在 Mac（Apple 芯片）上编译；
   - 发布一个 release，附件是 `DeepSeek-Bot-<版本>-mac-arm64.zip`。
4. **坑：GitHub 的 Mac 编译机经常排队十几分钟后被取消。** 被取消就重跑：
   ```
   gh api -X POST repos/AvenYQ/DS-Bot/actions/runs/<id>/rerun-failed-jobs
   ```
5. 这个会话不能自己创建 release（403），只能通过 CI 发。`gh` 的 GraphQL 被拦，只能用 `gh api` 调 REST 接口。
6. **当前线上最新版：`v0.2.4-aven.4`**（2026-10-31 09:27 发布）。内容是值房图动效、印章时机修正、侧栏拖拽收拢、输入框按钮对齐，详见 `docs/plans/2026-10-31-aven-seals-court-board-drag.md`。

## 五、自动更新（已验证可用）

- 这个 app 没有苹果开发者证书，用的是我们自己写的更新器。
  1. 发现新版本后弹窗，按钮是「立即更新」。
  2. 后台下载 zip（走系统代理，60 秒没进度就判失败），用 GitHub 提供的 sha256 校验。
  3. 解压后由一个脚本等 app 退出，替换 `/Applications/DeepSeek Bot.app`，再重新打开。
- 今天修了一个 bug：以前点「立即更新」只会打开发布页，没有真正自己更新。修复在测试版 aven.2.2 里，也在 aven.3 里。
- **已验证（10-30 中午）：** Aven 从测试版 0.2.4-aven.2.2 点「立即更新」，顺利更新到 aven.3。以后发版他点一下就行。
  - 如果以后出问题：日志在 macOS 临时目录下的 `ds-bot-update-*/swap.log`。

## 六、每日同步作者更新

- CI 里本来配了每天定时同步，但在 fork 仓库上从来没触发过。
- 现在由一个定时任务「DS Bot 每日同步作者更新」兜底：每天凌晨 4:47（北京时间）在云端运行。
  - 没有新东西就不打扰；
  - 编出新版就推送消息；
  - 合并冲突就通知 Aven，**不自己改代码**。
- 作者改动大时，比如 0.2.4 重做了侧栏，会合并冲突，需要手动合并：以作者的新代码为底，把我们的改动逐项移植上去。

## 七、我们做过的改动（都在 `aven/dev` 里，可用 `git log` 查）

### 侧栏与窗口
- **置顶**：置顶的 bot 以方块形式排在侧栏顶部，主 bot 默认置顶，任何 bot 都可以置顶或取消（`sidebar.js` 的 `sectionGroups`，`sources.js` 的 `isPinned`）。
- **拖动排序**：长按 280 毫秒后可拖动行、方块、分组标题，也能把 bot 拖进别的分组（`drag-sort.js`）。
- **主 bot 角标**：圆形橙色印章，里面是白色五角星（`styles.js`）。
- **作者 0.2.4 的新侧栏**：展开 / 收起成 88px 头像栏 / 抽屉 / 隐藏四种状态。
  - 收起时，Mac 红绿灯移到头像栏正中（`main.mjs` 的 `MAC_LIGHTS rail {x:14,y:23}`，`preload.cjs` 的 `watchRail` 监听 `.bt-leftcol[data-left]`）。
  - 侧栏和聊天区用同一条曲线一起滑动，0.32 秒。
- **⌘Q 退出**：苹果菜单里加了「退出 DeepSeek Bot」（作者原本只能从菜单栏图标退出）。

### 聊天区
- **GIF 头像**：每个显示位置用单独的 blob 拷贝，点击头像时动图不会从头播（`mark.js`）。
- **口头禅**：每个 bot 可以设 6 条以内，工作时代替"思考中…"显示（`phrases.js`、`cells.js`、`activity-row.js`）。
- **贴底滚动**（`tail-keeper.js`）：
  - 内容变长时保持贴底；回复结束时内容变短，先撑住再缓缓收回。
  - 因为对话区变宽而变短时不撑（这修好了关闭右侧面板时跳到顶）。
  - 贴底时关闭浏览器的 scroll anchoring。
- **底部预留空间**：对话最底部常驻 36px，"思考中"那一行（头像加口头禅）在这块空间里出现和消失，不推动对话（`styles.js` 的 `[data-chat-flow]` padding）。
- **空过程组**：DSH 每轮会插入一个"过程组"（思考、工具调用）。我们的界面把里面的内容都隐藏了，但空框会占 36px，导致发消息后对话被顶上去、间隔不均。现在由 `process-groups.js` 在页面绘制前把空组标成 `data-bt-empty` 收起来。
- **气泡节奏（对标 Grok）**：同一个人连着说的气泡间隔 4px，换人说话一律 14px。由 `process-groups.js` 给每条可见消息标 `data-bt-gap=same/turn`，"发送中"的回显气泡也是 14px。
- **字体（对标 Grok）**：
  - 聊天正文比 DSH 的字号设置大 1px，默认 15px、行高 24px；
  - 全局用 macOS 默认渲染（`-webkit-font-smoothing:auto`），Aven 非常讨厌细字和颗粒感；
  - 侧栏名字字重 500，分组标题 400；
  - DSH 最小的 11px、12px 字号各加 1px；设置页 14/13px，颜色加深。
- **朱批印章**：用户回复"准 / 驳回 / 知道了"等，会在大臣气泡角上盖章，三种形制（Aven 已确认喜欢）：
  - 准：朱红实心方印，字是纸白色；
  - 驳回：墨色竖长印，反方向倾斜；
  - 已阅：小椭圆印，线条细、颜色淡。
  - 三枚都有纸纹颗粒（`styles.js` 的 `.bt-stamp`，`seal.js`）。

## 八、测试环境（在云端会话里）

- 不连真模型的模拟环境：一个假模型 `ds-bot/dev/mock-llm.mjs`，加上 `dsh web`（DSH 0.2.1-rc.4），用 Playwright 截图和录屏。
- 假模型的触发词：
  - 「长回复」：慢慢流式输出多段；
  - 「思考一下」：带思考过程；
  - 「团队情况」：会调用工具；
  - 「卡片」：带提问卡片。
- **局限**：Linux 上没有苹方和宋体，字形、粗细必须到 Aven 的 Mac 上看。假模型的行为也和真实 DeepSeek 不完全一样，今天的跳动问题就是在真机上才暴露的。
- **真机调试**：做一个测试版装到他的 Mac 上（版本号用 `0.2.4-aven.X.Y`，比正式版小，不影响之后的自动更新）。需要时可以临时加滚动记录器，见 commit `721a2c5`，用完删掉。
- 控制他的电脑：
  - 后台往输入框打字，要先点一下输入框，再用 `target: focused` 输入；
  - 菜单里点不到「退出」时，请他自己退出 app。

## 十、下一步：加功能

Aven 认为 UI 问题基本解决，接下来要加功能。首辅·张居正提过三个方向（Aven 还没拍板，需要和他确认）：

1. **朝会**：用群聊建「内阁」「六部」等议事厅。Aven 抛一个题目，几位大臣当场各说各的、互相驳，首辅最后裁决。DSH 现成支持 `create_group` 建群，最多 12 人，群里能 @ 指定谁说话。首辅建议先做这个，因为最能体现特色、不用写代码就能试。
2. **六部会签**：丢一份文档进来，走一遍流程：工部审技术 → 户部审成本 → 刑部审风险 → 礼部审格式 → 首辅票拟 → Aven 朱批。产出一份带批注的文件。
3. **拟物看板**：一个外挂页面，展示六座衙门、十九间值房，谁在办事、谁闲着、谁刚回过话一眼看到，再配上自动生成的「朝会实录」。

另外两点提醒：
- 首辅建议慎做"升迁贬谪的游戏化"（"裁官"是高风险操作）。
- 成本：每唤醒一位大臣就是一次模型调用，设计上要"按需召人"，不要一开口全员都动。
