# 2026-10-31 聊天顶部头像与名字胶囊

按 Aven 的截图改聊天区顶部的名称胶囊：头像成为完整的方圆角头像，名字做成小胶囊压在其下沿。只动这一处，侧栏、名册、设置预览、消息里的发言人头像都不改。

## 量出来的参考（Muse 10.1，非官网描述）
从用户截图按像素测量（截图约 1.55 倍缩放换算成 CSS 尺寸）：
- 头像直径 93px → 约 60 CSS px；名字胶囊高 43px → 约 28 CSS px。
- 胶囊宽度约头像的 0.79 倍（短名字时比头像窄）。
- 胶囊上沿与头像下沿约 5% 直径的咬合。

## 采用
- 三档：小 36 / 中 46 / 大 56 CSS px；中档贴近 Muse。
- 名字胶囊：高 22，字号 12，圆角 999，胶囊上沿压进头像约 9% 直径。
- 沿用 DS Bot 自己的表面色、0.5px 描边和弹簧动效；不复制对方代码。
- 大档时会话顶部留白加 12px，避免压到第一条消息。
