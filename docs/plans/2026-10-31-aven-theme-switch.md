# 2026-10-31 小朝廷主题开关

DS Bot 本身是一套通用的 Bot 团队界面，小朝廷是我们给它做的一层主题。这一轮把这一层从「写死」改成「可以关掉」。

## 开关

- 位置：设置 → 外观，原来的「朝堂用语」一行，现在叫「主题」。
- 存储：沿用 `state.prefs.court`（缺省 = 开启），不新增字段，老数据不用迁移。
- 关掉后的判定只有一个地方：`src/client/sources.js` 的 `courtTheme(roster)`，`prefs.court === false` 才算关。
- 页面同步标了 `body[data-bt-court=on|off]`，纯装饰样式可以只靠 CSS 处理；现有配色那一行同时改名「配色」，把「主题」这个名字让出来。

## 关掉后消失的东西

| 位置 | 有主题 | 无主题 |
| --- | --- | --- |
| 侧栏头像角标 | 印章，写「办 / 批 / 询」 | 同色小圆点，不写字（红=办完、琥珀=等批、石青=等答） |
| 侧栏底部的值房图入口 | 「小朝廷值房」按钮，点开 3D 看板 | 按钮不渲染；看板不挂载，已打开的会关闭并释放 WebGL 场景 |
| 消息上的朱批 | 「准 / 驳回 / 已阅」印章 | 不盖章，只剩文字 |
| 大臣口头禅 | 建言的措辞（斟酌中、遵旨办理…） | 通用文案；行高不变，不会跳动 |
| 朝堂用语 | 状态行用朝廷说法 | 一律通名 |
| 「小朝廷值房」等文案 | 照旧 | 不出现 |

## 不受开关影响

拖拽排序（含分组收拢、闪烁修复）、印章/按钮对齐、贴底滚动、字体与配色、动效修复、性能——这些是 bug 修复和优化，始终生效。

## 动效

从 `src/client/motion.js` 里挑的曲线：盖印与小圆点用 `SPRING_POP`，值房图入口出现时用 `SPRING_TAP`（淡入 + 轻微上移），`prefers-reduced-motion` 下全部关闭。

## 验证

- 隔离数据跑打包后的应用：开 = 入口在、印章写「询」；关 = 入口消失、8px 石青圆点、`body[data-bt-court=off]`。
- `npm test` 1303 通过 / 2 跳过，`build-client --check` 与 `npm run lint` 通过。
- 侧栏测试覆盖了「印章 / 圆点」两种形态，`courtTheme` 的默认值单测覆盖了缺省开启。

## 已知限制

- 关闭时 3D 看板直接卸载，没有退场动画。
- 头像本身不受开关影响（按安排后面另做）。
