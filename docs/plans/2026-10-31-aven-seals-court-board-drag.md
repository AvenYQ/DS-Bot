# 2026-10-31 印章时机、值房图动效与侧栏拖拽

本轮的改动范围：侧栏状态印章、值房图（小朝廷 3D 看板）动效、侧栏拖拽排序、输入框按钮对齐。发布为 `0.2.4-aven.4`（Aven 口中的「4.0」）。

## 1. 三种印章：办 / 批 / 询

侧栏每个 Bot 的头像左下角显示一枚小印，取代原来含糊的问号角标：

| 印 | 颜色 | 含义 | 数据来源 |
| --- | --- | --- | --- |
| 办 | 朱红 | 干完了，你还没看 | `completionUnread` |
| 批 | 琥珀 | 等你批准（工具审批） | `work.approvals` |
| 询 | 石青 | 等你回答（提问卡片 / 交互视图） | `roster.questions`、`roster.views`、`pendingInteraction` |

优先级：批 > 询 > 办。窄栏和展开侧栏都在头像左下角；主 Bot 的五角星仍在头像右下，两者不再互相遮挡。

实现集中在 `ds-bot/src/client/live-state.js` 的 `liveStateOf`，侧栏行（`sidebar.js` 的 `Seal`）和值房图（`court-board/state.js`）读同一份推导，避免两处状态漂移。

## 2. 「办」不该抢在提问前面

**问题**：大臣先回一句话，侧栏立刻盖上「办」，紧接着选项卡片到达又变成「询」，看起来像差事已经结束。原因是会话状态和 roster 是两条独立更新：前者先到，后者要等下一次轮询（前台 1.5s）。

**做法**：`createDoneHold` / `useDoneHold`。观察到「完成未读」时先不盖章，主动拉一次 host state 确认（`index.js` 的 `confirmCompletion`：当前 part 没变、没有问题、没有交互视图、没有运行中的 turn、没有待批审批）之后才显示「办」。拉取失败或结果过期不放行，1.5s 后重试；提问、审批、重新开始、已读都会立刻撤销这次等待。

**限制**：如果 host 状态本身滞后到「完成」先落地，仍可能有极短的过渡；要做到彻底可靠需要 DSH 提供按 turn 关联的原子完成结果。

## 3. 值房图动效

- 名册里点大臣，镜头平滑飞过去；手动操作地图会打断镜头；`prefers-reduced-motion` 下直接跳位。
- 官员卡片从右侧进入、名册从左侧进入；关闭时不再瞬间消失，而是保留 180ms 播退场（`useExitValue`），退场期间面板不可交互。
- 3D 印章只在该大臣状态变化时落一次（`sealAt`），落定后保持静止，不再持续浮动；卡片和名册里的印章同样只落一次。
- 舞台关闭时销毁 WebGL 场景、重开重建，避免引用已脱离文档的节点。

## 4. 侧栏拖拽

- **拖分组**：长按组名后，组内大臣用临时的视觉副本向组名收拢（真实行立刻退出布局，保证落点判定用的是最终位置），拖动对象只剩组名一行；落位后组员轻柔展开，原本收起的分组仍保持收起。
- **拖单个大臣**：保留原来的跨组、置顶逻辑，落位时有一次轻微回弹。
- 取消（Esc、指针取消、组件卸载、更新失败）都不提交排序，并恢复临时隐藏和变换；`pointercancel` 不再当作正常落位处理。
- 修过一处闪烁：收拢用的复制行原本在淡出动画结束时立刻移除，而那一层是覆盖在列表上的固定层，移除时浏览器会把被覆盖的那一条先按旧内容呈现一帧，看起来就是人名全部闪回来。现在复制层挂在 `body` 上、用过渡淡出、并且留到落位之后再移除。
- 动画 200ms 上下，`prefers-reduced-motion` 下全部关闭。

## 5. 两处对齐修复

- 输入框右侧主按钮（工作时是停止按钮）比耳机麦克风高 2px：DSH 给按钮带了 `translateY(-2px)`，插件侧 `transform:none` 覆盖掉。
- 头像印章统一到左下角：之前主 Bot 的印章压住五角星，窄栏收起后更明显。

## 6. 发版流程里踩到的两个坑

1. `app/package-lock.json` 与 `package.json` 不同步（缺 `@earendil-works/pi-ai/node_modules/ws@8.22.0`），CI 的 `npm ci` 直接失败。修法：只补这一条依赖，不要用 `npm install --package-lock-only` 重写整个锁文件——它会顺手删掉其他平台包的 `libc` 字段，把无关平台搅乱。
2. `git merge aven/dev` 到 `aven/custom` 时，`package.json` 冲突按规矩保留发布分支的版本号（`--ours`），结果把 `ds-bot/package.json` 里值房图需要的 `three` 依赖一起丢了，CI 报 `Could not resolve "three"`。**冲突只解决版本号字段，依赖字段要逐项核对。**
